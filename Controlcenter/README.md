# Control Center

Frontend V1 del command center web para `cloudvienna`.

## Requisitos

- Node.js 20+
- Backend FastAPI operativo

## Variables

Crear `.env` en esta carpeta si quieres cambiar el backend:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
