# Controlcenter Interface System

## Direction And Feel
- Product posture: front-desk and back-office control center for a martial arts academy.
- Desired feel: precise, calm, compact, and operational.
- Core metaphor: live student and session records handled from a reception desk, not a generic SaaS dashboard.
- Interaction tone: fast to scan, low-drama, high-signal.

## Domain Anchors
- Reception workflow
- Living student records
- Tatami scheduling
- Administrative control and audit
- Role-based operations

## Color World
- Cold paper and whiteboard surfaces
- Blue ink and administrative labels
- Blue-gray tatami and charcoal equipment tones
- Matte steel and frosted glass
- Controlled indigo for navigation and selection
- Green and amber only for real status meaning

## Signature
- Ficha operativa: key entities should read like operational record folders with a compact identity band and a dedicated status/actions area.
- Screens should feel like an academy control desk, not interchangeable metric-card dashboards.

## Depth Strategy
- Use borders-first hierarchy with subtle surface shifts.
- Avoid glow, decorative gradients, and attention-seeking shadows in app surfaces.
- Use shadows sparingly and only for overlays or temporary floating elements.

## Spacing Base Unit
- Base unit: 4px.
- Typical component rhythm: 8px, 12px, 16px, 24px.
- Dense operational screens should prefer tighter vertical rhythm over large card padding.

## Typography
- Use a more distinctive operational heading face than the default system/Inter pairing.
- Navigation and headings may use a semi-condensed or compact sans.
- Body and forms should use a neutral sans with strong readability.
- Dates, times, and metrics should use tabular numerals.

## Component Patterns
- Panel: quiet bordered surface, structured header, no glass effect.
- Stat block: operational summary block, not glowing KPI card.
- Data table: explicit empty state, dense rows, stable alignment, muted separators.
- Field controls: unified custom field/select/date controls with consistent tokens across themes.
- Detail pages: identity header plus grouped record sections, with status/actions given a consistent dedicated zone.

## Defaults To Reject
- Generic glowing dashboard cards
- Dark-first utility styling patched for light mode
- Native select/date/time controls as final UI
- Decorative gradients that do not encode meaning
- Success-green used as the primary brand accent
